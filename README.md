# 🚢 Titanic Exploratory Data Analysis (EDA)

An Exploratory Data Analysis (EDA) project on the famous **Titanic Dataset** using Python. This project analyzes passenger demographics, ticket information, survival rates, and feature relationships through data cleaning, visualization, and statistical exploration.

## 📖 Project Overview

The Titanic dataset is one of the most well-known datasets in data science and machine learning. This project aims to understand the factors that influenced passenger survival by performing comprehensive exploratory data analysis.

The notebook includes:

- Data loading and inspection
- Data cleaning and preprocessing
- Handling missing values
- Descriptive statistics
- Data visualization
- Correlation analysis
- Key insights and conclusions

## 🚀 Getting Started

### Prerequisites

- Python 3.10+
- Jupyter Notebook or VS Code
- Git

### Clone the Repository

```bash
git clone https://github.com/rex03092005/Titanic-EDA-Analysis.git
```

### Navigate to the Project

```bash
cd Titanic-EDA
```

### Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### Launch Jupyter Notebook

```bash
jupyter notebook
```

Open:

```
Titanic_EDA.ipynb
```

## 📌 Key Insights

Some insights explored include:

- Female passengers had a higher survival rate than male passengers.
- First-class passengers had better survival chances.
- Younger passengers generally had higher survival rates.
- Fare and passenger class showed relationships with survival.
